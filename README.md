# MatdaanGuide
AI-powered election guide that helps users check eligibility, register, and vote through a personalized, step-by-step experience. Includes chatbot support, timeline updates, myth-busting, and polling booth locator to make voting simple and accessible.

MatdaanGuide is an AI-powered election guidance platform designed to simplify the voting process for citizens, especially first-time voters. It transforms complex and often confusing election procedures into a clear, interactive, and personalized experience that helps users confidently participate in the democratic process.

The platform works by collecting basic user details such as age, location, and voter status, and then providing tailored guidance on eligibility, registration, deadlines, and voting procedures. Instead of overwhelming users with static information, it offers a structured, step-by-step journey that walks them through every stage of voting, from checking eligibility to casting their vote.

To make the experience more engaging and practical, VoteWise includes an AI-powered chatbot that can answer common election-related questions in simple language. It also features an election timeline that highlights important dates, a myth-versus-fact section to address misinformation, and a polling booth locator that helps users find their nearest voting center easily.

The project is built using modern web technologies such as HTML, CSS, JavaScript (or React), along with a backend powered by Node.js or Flask. It integrates AI capabilities through APIs and may use map services for location-based features.

VoteWise is primarily aimed at first-time voters, students, and young citizens who need accessible and easy-to-understand election guidance. A special “First-Time Voter Mode” further enhances usability by offering a simplified interface with minimal text and clear visual cues.

This project demonstrates how technology, especially AI and personalization, can be used to make civic processes more inclusive, intuitive, and user-friendly.
